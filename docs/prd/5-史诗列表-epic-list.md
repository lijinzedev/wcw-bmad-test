# 5. 史诗列表 (Epic List)

- **Epic 1: 核心基础与风险/隐患管理**
  - **目标:** 搭建系统基础框架和权限体系，上线风险录入和隐患排查闭环管理的核心功能，并支持移动端上报。
- **Epic 2: 监督检查与流程扩展**
  - **目标:** 为上级单位开发在线监督检查功能，并上线不安全行为管理和红黄牌警示模块。
- **Epic 3: 数据分析与决策支持**
  - **目标:** 开发安全考核、事故管理、对标分析等功能，并构建数据驾驶舱。
- **Epic 4: 职业健康与智能化集成**
  - **目标:** 上线职业健康管理模块，并完成与安全监控系统的对接，实现智能预警。
