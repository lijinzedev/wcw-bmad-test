# 8. Epic 3: 数据分析与决策支持

**史诗目标:** 激活数据的价值。开发安全考核、事故管理、对标分析等功能，并为各级管理层构建数据驾驶舱，提供数据驱动的决策支持。

### Story 3.1: 安全绩效考核管理

- **As a** 公司或集团级管理员,
- **I want** 系统能根据双体系的运行数据自动生成安全绩效考核结果,
- **so that** 我可以公平、高效、量化地评估各单位的安全管理水平。

**验收标准:**

1. 管理员可以配置考核周期和各项指标的权重。
2. 系统能自动从数据库中拉取原始数据进行计算。
3. 系统可以生成各单位的考核得分和排名报表。
4. 报表支持下钻功能，可以查看具体得分或失分项的明细。

### Story 3.2: 安全事故管理与分析

- **As a** 矿级安全管理员,
- **I want** 在线填报发生的各类安全事故，并能将其与相关的风险点和隐患进行关联,
- **so that** 我们可以从事故中学习，持续改进风险管控措施。

**验收标准:**

1. 用户可以上报事故，记录时间、地点、类型、伤亡情况等信息。
2. 系统支持事故调查报告等文件的上传。
3. 在填报或分析事故时，用户可以将事故与系统中已存在的风险点或隐患进行关联。
4. 系统可以统计事故趋势，并高亮显示与事故关联频次最高的风险点。

### Story 3.3: 跨单位安全对标

- **As a** 集团安全管理部门用户,
- **I want** 在系统中对各单位的关键安全指标进行横向对比（对标）,
- **so that** 我可以发现管理上的亮点和短板，促进经验推广。

**验收标准:**

1. 用户可以选择多个单位和多个指标进行对标。
2. 系统能以表格或图表的形式清晰地展示对标结果。
3. 用户可以将对标模板保存，以便进行定期的、标准化的分析。

### Story 3.4: 管理驾驶舱开发

- **As a** 各层级管理者,
- **I want** 一个定制化的数据驾驶舱，集中展示我最关心的核心安全指标,
- **so that** 我可以快速掌握安全生产的总体态势。

**验收标准:**

1. 系统为矿级、公司级、集团级三个层级提供不同侧重点的驾驶舱界面。
2. 驾驶舱的图表数据能从系统中实时获取并展示。
3. 驾驶舱的关键指标应包括但不限于：实时风险总数、待处理隐患数、重大隐患占比等。
4. 驾驶舱的图表支持基本的交互，如点击可跳转到详细数据列表。
