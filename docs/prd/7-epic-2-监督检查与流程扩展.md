# 7. Epic 2: 监督检查与流程扩展

**史诗目标:** 在核心功能之上，为二级公司、集团和政府监管部门开发在线监督检查功能，并上线不安全行为管理和红黄牌警示模块，将管理流程扩展到所有层级。

### Story 2.1: 不安全行为管理

- **As a** 矿级安全管理员,
- **I want** 记录、处理和分析员工的“三违”等不安全行为,
- **so that** 我可以规范员工操作，并为安全培训提供数据支持。

**验收标准:**

1. 管理员可以在PC端录入不安全行为，记录时间、地点、当事人、行为描述、违反规定和处理措施。
2. 系统可以生成不安全行为管理台账，并支持按人员、时间、行为类型进行查询。
3. 系统可以统计分析高发的不安全行为类型和个人。

### Story 2.2: 公司及集团级监察

- **As a** 二级公司或集团的安全监察员,
- **I want** 在系统中制定检查计划，并在线记录对下属矿井的检查过程和发现的隐患,
- **so that** 监督检查工作可以系统化、无纸化，并与隐患管理流程直接联动。

**验收标准:**

1. 授权用户（公司/集团级）可以创建检查任务，并指定检查的矿井、范围和时间。
2. 检查人员可以在PC或移动端，对照检查清单执行检查，并记录结果。
3. 检查中发现的隐患可以直接录入系统，这些隐患会自动标记为“公司/集团级督办”，并进入已建立的隐患闭环流程。
4. 检查任务完成后，可以生成检查报告。

### Story 2.3: 政府监管端口

- **As a** 政府监管员,
- **I want** 登录一个特定的系统端口，查看所辖煤矿的安全数据并记录我的执法检查情况,
- **so that** 我可以高效履行监管职责，并在线跟踪重点督办事项。

**验收标准:**

1. 存在一个独立的、安全的登录入口供政府监管员使用。
2. 监管员登录后，只能查看其管辖范围内矿井的风险清单和隐患台账（只读权限）。
3. 监管员可以录入执法检查中发现的新隐患，这些隐患会被特殊标记（如“政府督办”），并进入矿端的整改流程。
4. 监管员可以上传执法文书的电子版附件。
5. 监管员可以清晰地看到其督办的所有隐患的当前整改进度。

### Story 2.4: 红黄牌管理

- **As a** 公司或集团级管理员,
- **I want** 对问题频发或整改不力的单位进行电子化的红黄牌警示,
- **so that** 我可以建立一个有效的警告和升级管理机制。

**验收标准:**

1. 系统管理员可以配置触发红黄牌的规则（例如：一个月内出现N条同类重大隐患）。
2. 当单位满足规则时，系统会自动向管理员发送黄牌预警通知。
3. 管理员可以手动确认对某个单位进行“挂牌”，并记录原因、期限和摘牌条件。
4. 被挂牌单位在系统中有明显的红色或黄色标识。
5. 满足摘牌条件后，管理员可以手动进行“摘牌”操作。
