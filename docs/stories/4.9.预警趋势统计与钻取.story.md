# Story 4.9: 预警趋势统计与钻取

## Status
Ready for Dev

## Story
As 安全管理层,
I want 在PC端查看预警趋势、分布与钻取分析,
so that 能够从宏观角度监控预警整体走势，发现异常波动，并快速定位到具体预警列表。

## Acceptance Criteria
1. 新增“预警分析”页面：支持按时间范围（本周/本月/自定义）展示预警趋势折线图、按严重级别堆叠柱状图、按指标TOP N柱状图。
2. 鼠标点击图表某一时间点或指标条时，可跳转到预警列表并自动带入过滤条件（时间段、指标或级别）。
3. 提供导出 CSV 功能：当前筛选条件下的预警统计数据与详细列表可导出（至少包含时间粒度、指标、级别、数量）。
4. 数据支持后端API分页与缓存（避免重复计算），并记录查询审计（时间、条件、操作者）。

## Tasks / Subtasks
- [ ] Task 1 (AC: 1-4) 后端：统计查询与导出
  - [ ] 新增 `AlertAnalyticsService`：基于预警表提供按日/周/月聚合、按 severity 占比、按 metric TOP N 查询
  - [ ] 新增接口：`GET /api/v1/analysis/alerts/trend`, `/distribution`, `/top-metrics`（支持时间范围、粒度、limit），结果缓存（5分钟）
  - [ ] 新增 `/api/v1/analysis/alerts/export` 导出接口（CSV），日志记录操作人+条件

- [ ] Task 2 (AC: 1-3) 前端PC：预警分析页面

  - [ ] 图表交互：点击数据点 -> 使用 router 导航到 `/alerts` 并附带 query（时间/指标/级别），页面应自动加载过滤结果
  - [ ] 导出按钮调用后端 CSV 下载

- [ ] Task 3 (AC: 2) 预警看板支持URL参数过滤
  - [ ] `AlertsBoardView` 支持读取 URL query（from,to,metric,severity），初始加载时据此过滤
  - [ ] `fetchAlerts` 调用附带这些参数

- [ ] Task 4 (AC: 4) 质量与文档
  - [ ] 后端：MockMvc 覆盖统计接口（含缓存命中、输入校验、导出）
  - [ ] 前端：Vitest 覆盖 AlertAnalyticsView 渲染与跳转逻辑
  - [ ] 文档：在架构文档“分析组件”章节补充预警分析流程、缓存策略和导出格式

## Dev Notes
- 聚合策略：使用数据库分组，日级粒度（DATE_TRUNC），若性能不足，可后续引入物化视图或异步统计。
- 缓存：可通过 `@Cacheable` 或简单的 ConcurrentHashMap + TTL 实现；条件较多时注意键组合。
- 导出：CSV 至少包含列（time_bucket, metricCode, severity, count）。
