# Story 4.2: 安全监控系统对接

## Status
DONE

## Story
**As a** 矿级安全管理员,
**I want** 双防系统能够自动接收来自安全监控系统的异常报警数据,
**so that** 我可以第一时间获知潜在的重大风险，实现技防与人防的联动。

## Acceptance Criteria
1. 系统已成功建立与至少一种主要安全监控系统（如瓦斯监控）的数据接口。
2. 管理员可以配置异常数据的报警阈值。
3. 当监控系统数据超过阈值时，双防系统内会自动生成一条高危预警信息。
4. 预警信息应包含时间、地点、超标数值等关键内容。
