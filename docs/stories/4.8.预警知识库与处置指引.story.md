# Story 4.8: 预警知识库与处置指引

## Status
DONE

## Story
As 安全管理员与一线责任人,
I want 为不同类型/级别的预警配置标准处置指引与知识条目，并在预警详情中自动推荐,
so that 现场人员可以迅速对照步骤进行处置，减少误判并形成经验沉淀。

## Acceptance Criteria
1. 管理端可创建/维护知识库文章（标题、正文、标签、适用指标/级别/地点模式、附件元数据），支持启停与全文搜索。
2. 当产生新预警或打开预警详情时，系统自动匹配推荐1-3条最相关的处置指引；匹配规则可按 metricCode/severity/locationPattern。
3. PC 端预警看板行内可快速查看推荐摘要并点击展开全文；移动端“我的预警”详情页显示推荐摘要与展开/折叠。
4. 所有知识库变更写入审计，文章可被标记为“过期/替换为X”；推荐记录可追踪（用于后续A/B与优化）。

## Dev Notes
### Matching 规则
- 按 `metricCode` 精确匹配优先；若有 `locationPattern` 则为包含匹配；`severity` 精确匹配加分。
- 混合优先级：score = metric(2) + severity(1) + location(1) + mapping.priority；取Top K（默认3）。
- 文章 `enabled=false` 或 `content` 为空则不返回。

### API Sketch
- `GET /api/v1/kb/articles?keyword=&tags=&enabled=&page=&size=` → 头 `X-Total-Count`/`X-Total-Pages`
- `POST /api/v1/kb/articles` body `{title,content,tags,attachments,enabled}`
- `GET /api/v1/monitoring/alerts?includeKb=true` → 每条记录增加 `kbRecommendations`

### Security & Audit
- 仅 ADMIN 可管理知识库；普通用户仅可读推荐。
- 审计字段至少包含 articleId/ruleId、operator、timestamp；推荐日志记录 alertId 与 articleIds。
