# Story 1.3: 风险清单管理

## Status
Done

## Story
**As a** 矿级安全管理员,
**I want** 在PC端系统性地录入、编辑和查询安全风险点,
**so that** 我可以建立并维护全矿的电子化安全风险清单。

## Acceptance Criteria
1. 用户可以按照专业、区域、岗位等维度创建新的风险点。
2. 创建风险点时，可以填写风险描述、事故类型、风险等级、责任单位/人和管控措施等字段。
3. 所有已录入的风险点以列表形式展示，并支持按条件筛选和关键词搜索。
4. 用户可以导出完整的风险清单为Excel文件。
