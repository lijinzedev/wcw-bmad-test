# Story 2.4: 红黄牌管理

## Status
DONE

## Story
**As a** 公司或集团级管理员,
**I want** 对问题频发或整改不力的单位进行电子化的红黄牌警示,
**so that** 我可以建立一个有效的警告和升级管理机制。

## Acceptance Criteria
1. 系统管理员可以配置触发红黄牌的规则（例如：一个月内出现N条同类重大隐患）。
2. 当单位满足规则时，系统会自动向管理员发送黄牌预警通知。
3. 管理员可以手动确认对某个单位进行“挂牌”，并记录原因、期限和摘牌条件。
4. 被挂牌单位在系统中有明显的红色或黄色标识。
5. 满足摘牌条件后，管理员可以手动进行“摘牌”操作。
