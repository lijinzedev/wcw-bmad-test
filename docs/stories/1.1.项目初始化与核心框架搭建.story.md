## Dev Notes
### 技术栈信息
- **后端语言**: Java 17 (LTS) [Source: architecture/3-技术栈-tech-stack.md]
- **后端框架**: Spring Boot 3.x (3.1.5) [Source: architecture/3-技术栈-tech-stack.md]
- **前端框架 (PC)**: Vue.js 3.3.4 [Source: architecture/3-技术栈-tech-stack.md]
- **移动端框架**: Uni-app 3.8.12 [Source: architecture/3-技术栈-tech-stack.md]
- **数据库**: PostgreSQL 15.4 [Source: architecture/3-技术栈-tech-stack.md]
- **Monorepo管理**: Nx 16.8.1 [Source: architecture/3-技术栈-tech-stack.md]
- **CI/CD**: Jenkins 2.414.2(LTS) [Source: architecture/3-技术栈-tech-stack.md]

### 项目结构信息
- **项目结构**: Monorepo结构，使用Nx管理 [Source: architecture/2-高层架构-high-level-architecture.md]
- **目录结构**:
  - apps/ - 存放可独立部署的应用
    - backend/ - 后端Java Spring Boot应用
    - frontend-pc/ - 前端PC Vue.js应用
    - frontend-mobile/ - 前端移动端 Uni-app应用
  - libs/ - 存放共享库和业务逻辑模块
  - tools/ - 存放构建、部署等脚本 [Source: architecture/9-项目源代码树结构-source-tree.md]

### API规范
- **根路径**: 所有API都将以 `/api/v1` 作为根路径
- **认证**: 除登录接口外，所有API请求的Header中都必须包含一个有效的JWT [Source: architecture/7-rest-api-规范-rest-api-spec.md]

### 数据库模式
- **用户相关表**: organizations, users, roles, user_roles
- **UUID主键**: 使用UUID作为主键，并启用uuid-ossp扩展
- **时间戳**: 包含created_at和updated_at字段 [Source: architecture/8-数据库模式-database-schema.md]

### 测试标准
- **后端测试**: 使用JUnit 5 / Mockito 5.9.3进行单元/集成测试 [Source: architecture/3-技术栈-tech-stack.md]
- **前端测试**: 使用Vitest / Cypress 0.34 / 13.2进行单元/E2E测试 [Source: architecture/3-技术栈-tech-stack.md]
