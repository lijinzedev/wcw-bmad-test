# Story 3.3: 跨单位安全对标

## Status
DONE
## Story
**As a** 集团安全管理部门用户,
**I want** 在系统中对各单位的关键安全指标进行横向对比（对标）, 
**so that** 我可以发现管理上的亮点和短板，促进经验推广。

## Acceptance Criteria
1. 用户可以选择多个单位和多个指标进行对标。
2. 系统能以表格或图表的形式清晰地展示对标结果。
3. 用户可以将对标模板保存，以便进行定期的、标准化的分析。
