# Story 1.5: 隐患闭环管理（PC端）

## Status
Done

## Story
**As a** 矿级安全管理员,
**I want** 在PC端对上报的隐患进行指派、跟踪、审核与验收,
**so that** 我能确保每一条隐患都得到有效闭环。

## Acceptance Criteria
1. 管理员可以在PC端的看板或列表中看到所有待处理的隐患。
2. 管理员可以将隐患指派给具体的整改责任人/单位。
3. 整改人可以提交整改报告和相关证据。
4. 指定的验收人可以对整改结果进行“通过”或“驳回”的操作。
5. 隐患的状态（待指派、整改中、待验收、已关闭）在全流程中清晰可见。
6. 系统能自动记录每个流程节点的时间和操作人，形成完整的台账。
