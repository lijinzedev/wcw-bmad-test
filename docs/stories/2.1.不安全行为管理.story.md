# Story 2.1: 不安全行为管理

## Status
Done


## Story
**As a** 矿级安全管理员,
**I want** 记录、处理和分析员工的“三违”等不安全行为,
**so that** 我可以规范员工操作，并为安全培训提供数据支持。

## Acceptance Criteria
1. 管理员可以在PC端录入不安全行为，记录时间、地点、当事人、行为描述、违反规定和处理措施。
2. 系统可以生成不安全行为管理台账，并支持按人员、时间、行为类型进行查询。
3. 系统可以统计分析高发的不安全行为类型和个人。
