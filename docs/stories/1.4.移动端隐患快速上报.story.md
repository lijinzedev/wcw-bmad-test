# Story 1.4: 移动端隐患快速上报

## Status
Done

## Story
**As a** 一线员工,
**I want** 通过手机App快速上报现场发现的隐患,
**so that** 信息能够第一时间进入系统，提升上报效率和准确性。

## Acceptance Criteria
1. 用户可以通过手机App登录系统。
2. 上报页面设计简洁，必填项少。
3. 用户可以拍摄或上传照片/视频作为隐患证据。
4. 用户可以进行文字描述，并支持语音输入转文字。
5. 提交成功后，用户在App内能看到自己的上报记录及处理状态。
