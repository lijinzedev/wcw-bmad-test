# Story 4.1: 职业健康档案管理

## Status
DONE

## Story
**As a** 职业健康管理员,
**I want** 在系统中建立和管理职业病危害因素、接害人员档案以及员工的健康体检记录,
**so that** 我可以实现职业健康信息的电子化和集中化管理。

## Acceptance Criteria
1. 管理员可以录入企业存在的职业病危害因素，并形成清单台账。
2. 可以建立接害人员档案，记录其接害岗位、时长等信息。
3. 可以录入和管理员工的岗前、在岗、离岗职业健康体检报告。
4. 系统能够筛选出需要进行健康复查或调岗的员工。
5. 可以为已确诊的职业病患者建立专门的病例档案。
