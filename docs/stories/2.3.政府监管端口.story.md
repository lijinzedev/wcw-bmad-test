# Story 2.3: 政府监管端口

## Status
DONE

## Story
**As a** 政府监管员,
**I want** 登录一个特定的系统端口，查看所辖煤矿的安全数据并记录我的执法检查情况,
**so that** 我可以高效履行监管职责，并在线跟踪重点督办事项。

## Acceptance Criteria
1. 存在一个独立的、安全的登录入口供政府监管员使用。
2. 监管员登录后，只能查看其管辖范围内矿井的风险清单和隐患台账（只读权限）。
3. 监管员可以录入执法检查中发现的新隐患，这些隐患会被特殊标记（如“政府督办”），并进入矿端的整改流程。
4. 监管员可以上传执法文书的电子版附件。
5. 监管员可以清晰地看到其督办的所有隐患的当前整改进度。
